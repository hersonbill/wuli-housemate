# 屋里 · 合租生活管家

面向年轻合租人群的可交互产品雏形，包含费用 AA、清洁值日、公共物品登记与消耗记录、室友公约管理。

项目使用原生 HTML、CSS 和 JavaScript，无构建依赖。数据仅保存在访问者当前浏览器的 `localStorage` 中，适合通过 GitHub Pages 直接部署和持续更新。

固定体验地址：https://hersonbill.github.io/wuli-housemate/

## 视觉与交互

生活手账式界面、原创 SVG 客厅及公共物品插画、可切换暖灯氛围、桌面侧栏与手机底部导航。费用采用收据布局，公约展示室友确认头像。动效兼容系统「减少动态效果」设置，弹窗支持键盘与 Escape。

首版保留的浏览器数据可继续使用。此演示不包含真实付款、账户鉴权或多人云端同步，切换室友用于评审体验；发布者限制仅用于展示产品规则，不是服务端权限控制。

## 本次完善

- 费用结算：选择微信、支付宝或银行卡 → 模拟处理 → 成功回执 → 结清。取消或关闭处理中的弹窗不会结清；不连接支付平台，不收集银行卡、密码等信息。新账单可选择截止日期，金额按整数分计算。
- 清洁排班：原生日历选择日期，小时 / 分钟下拉选择，自动显示星期；按完成时间升序排列，逾期在前，完成与撤销后重新计算状态。支持调整日期和负责人。
- 四类记录：保存发布者，只有当前演示身份为发布者才可删除，并有二次确认；编辑公约仍允许室友共同修改，修改后清空旧确认。
- 图案：四类发布表单提供 24 款本地 SVG 生活图案，选择会保存并显示在对应卡片。
- 首页：仅展示我的今日 / 逾期任务、低库存物品、我的逾期 / 72 小时内到期账单。每类最多 3 条，剩余信息到各模块查看。
- 环境动效：插画区域的微风、飘叶、绿植轻摆、热茶蒸汽；可关闭，关闭偏好会保存。离开可见区域、切到后台或打开弹窗时暂停，兼容系统减少动态效果。

## 兼容与边界

保留 `wuli_housemate_v1` 存储键，增加 `schemaVersion: 2`。种子演示记录补齐已知作者；自建旧记录没有作者时保留为空，不猜测归属。无法解析的旧值日时间保留原文，可通过「改时间」补全；无截止日期的旧账单不混入临期提醒。重置演示会清除本浏览器的数据，请谨慎使用。

样式位于 `design.css`，视图位于 `views.js`，客厅插画位于 `art.js`，数据与交互位于 `app.js`。新增图案、迁移、时间、结算及动效逻辑位于 `features.js`。视觉说明见 `DESIGN.md`。

验收：`node tools/visual-qa.cjs`。设置 `WULI_QA_URL` 为固定网址后可验收线上版本。报告与截图输出到 `artifacts/design-v3/`，浏览器测试使用隔离数据，不改动访问者的记录。

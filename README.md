# 屋里 · 合租生活管家

面向年轻合租人群的可交互产品雏形，包含费用 AA、清洁值日、公共物品登记与消耗记录、室友公约管理。

项目使用原生 HTML、CSS 和 JavaScript，无构建依赖。数据仅保存在访问者当前浏览器的 `localStorage` 中，适合通过 GitHub Pages 直接部署和持续更新。

固定体验地址：https://hersonbill.github.io/wuli-housemate/

## 视觉与交互

生活手账式界面、原创 SVG 客厅及公共物品插画、可切换暖灯氛围、桌面侧栏与手机底部导航。费用采用收据布局，公约展示室友确认头像。动效兼容系统「减少动态效果」设置，弹窗支持键盘与 Escape。

首版保留的浏览器数据可继续使用。此演示不包含真实付款、账户鉴权或多人云端同步，切换室友用于评审体验；发布者限制仅用于展示产品规则，不是服务端权限控制。

## 本次完善

- 费用结算：选择微信、支付宝或银行卡 → 模拟处理 → 成功回执 → 结清。取消或关闭处理中的弹窗不会结清；不连接支付平台，不收集银行卡、密码等信息。新账单可选择截止日期，金额按整数分计算。
- 清洁排班：原生日历选择日期，小时 / 分钟下拉选择，自动显示星期；按完成时间升序排列，逾期在前，完成与撤销后重新计算状态。支持调整日期和负责人。
- 四类记录：普通成员只能删除自己的发布；房主可删除空间内所有记录，均有二次确认。编辑公约仍允许室友共同修改，修改后清空旧确认。
- 图案：四类发布表单提供 24 款本地 SVG 生活图案，选择会保存并显示在对应卡片。
- 首页：紧凑插画 + 一份有优先级的待办清单，默认显示 5 件，可展开其余事项。突出逾期、用完物品和今日值日，兼顾临期账单与待确认公约；首项突出，其他项弱化。点击后精准定位到模块内的具体记录，不在首页重复业务操作。其他室友已认领的物品仅显示汇总说明，避免重复采购。
- 环境动效：插画区域的微风、飘叶、绿植轻摆、热茶蒸汽；可关闭，关闭偏好会保存。离开可见区域、切到后台或打开弹窗时暂停，兼容系统减少动态效果。
- 空间设置：分为空间、成员、外观、演示数据四页。点击侧栏空间名（手机点顶栏空间名）创建或切换空间，各空间数据隔离。房主可改名、添加/移除演示成员、生成邀请和转让房主。
- 退出与交接：未结清应付/应收款阻止离开，未完成家务需交接，采购认领释放；历史成员姓名和分摊不变。房主离开前先转让；最后一人离开后归档，不抹去历史。
- 分享邀请：可复制链接，房主可更新令牌使旧邀请失效。同浏览器内可演示加入；另一浏览器只能预览邀请，不会伪装完成跨设备加入或同步。不分享账单、流水或完整成员目录。
- 三套主题：暖居手账（纸感侧栏）、都市编辑部（横向导航与双栏）、深夜公寓（深色窄栏与分栏待办），切换不改变业务数据。外观偏好跨空间保留。
- 附加细节：昵称修改、空间变更记录、全量 JSON 备份导出、重置前自动备份，以及未加入任何空间时的引导页。

## 兼容与边界

新存储键为 `wuli_housemate_spaces_v3`。首次升级读取旧 `wuli_housemate_v1`，原文备份到 `wuli_housemate_backup_before_spaces_v1`，旧键不删除。旧记录完整迁入原空间，小林为示例房主；新空间默认只有创建者。自建旧记录没有作者时保留为空，不猜测归属，但房主仍可管理。无法解析的旧值日时间保留原文，可通过「改时间」补全；无截止日期的旧账单不混入临期提醒。重置前备份当前数据到 `wuli_housemate_backup_before_reset`，仍应谨慎使用。

基础样式位于 `design.css`，主题与空间控件样式位于 `themes.css`；视图位于 `views.js`，客厅插画位于 `art.js`，基础交互位于 `app.js`。图案、时间、结算及动效位于 `features.js`，多空间/成员/主题管理位于 `spaces.js`。视觉说明见 `DESIGN.md`，业务规则与迁移决策见 `SPACE_BLUEPRINT.md`。

验收：`node tools/visual-qa.cjs` 和 `node tools/spaces-qa.cjs`。设置 `WULI_QA_URL` 为固定网址后可验收线上版本。报告与截图输出到 `artifacts/design-v5/` 与 `artifacts/spaces-v5/`，测试使用隔离浏览器，不改动访问者的记录；手机验证为模拟视口，非实体设备。
